Use on Android & Windows

🤖 Android Phone / Tablet

Install as an App on Android:

  1. Make sure your phone is connected to the same Wi-Fi network.
  2. Open Google Chrome on your Android phone.
  3. Type this address into Chrome:
    http://10.184.103.76:3000
  4. Tap Chrome's Menu (⋮) and tap "Install app" or "Add to Home screen".
  5. MemoryBloom will now appear on your home screen as a full-screen native app!
Or Scan QR Code with Phone Camera:
💻 Windows PC / Laptop

Use as a Desktop App on Windows:

  1. In Microsoft Edge or Chrome, click the Install App icon (⊕) in the top address bar.
  2. Or double-click the included Launch-Windows.bat shortcut in the project folder to open in standalone desktop window mode.
  3. It will launch in its own window without browser tabs or distractions!
